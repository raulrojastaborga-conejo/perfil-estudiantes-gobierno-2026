# Centro Mundial 2026

Sitio personal para seguir el Mundial 2026 desde Chile continental.

## Objetivo

Crear una página en GitHub Pages con:

- Calendario de partidos.
- Horarios en Chile continental.
- Canales de transmisión.
- Resultados editables.
- Tablas automáticas por grupo.
- Base de selecciones y jugadores.
- Modo simulador.
- Preparación para conectar una API deportiva.

## Estructura

```text
centro-mundial-2026/
├── index.html
├── README.md
├── assets/
│   └── styles.css
├── js/
│   └── app.js
```

## Nota sobre imágenes y logos

Este proyecto evita usar logos oficiales FIFA o fotos de futbolistas con copyright. El diseño usa recursos visuales propios, emojis, gradientes, banderas y una estética futbolera general.

Más adelante se pueden incorporar imágenes libres o APIs con licencias claras.
