Reportes internos y estadísticas

Página interna para ordenar solicitudes de información, reportes, bases, estadísticas y antecedentes para gestión, calidad, acreditación u otras unidades.

Qué cubre esta página

Incluye
  • Solicitudes de datos agregados.
  • Reportes para gestión interna.
  • Antecedentes para calidad o acreditación.
  • Seguimiento de archivos y fuentes.
No incluye
  • Certificados individuales.
  • Resoluciones académicas.
  • Entrega de datos sin respaldo o autorización.
Cuidado

Separar reportes agregados de información individual. Usar fuente, fecha de corte y responsable de elaboración.

Flujo base

Solicitud→Definir pregunta→Identificar fuente→Extraer datos→Validar→Entregar→Archivar versión

Campos mínimos del reporte

CampoUsoCuidado
Solicitante/unidadIdentificar destino del reporte.Confirmar competencia.
Pregunta o requerimientoEvitar reportes ambiguos.No asumir variables no pedidas.
FuenteSistema, planilla o documento base.Indicar si la fuente tiene limitaciones.
Fecha de corteDar trazabilidad temporal.Evitar mezclar cortes distintos.
ResponsableIdentificar quién elaboró/revisó.Permite repetir o auditar.
VersiónControl documental.Evitar múltiples archivos finales.

Tipos frecuentes

TipoEjemplo de usoSalida probable
Reporte de matrículaCupos, inscritos, continuidad.Tabla o resumen.
Reporte académicoAvance, egreso, aprobación.Base filtrada o indicador.
Reporte para acreditaciónAntecedentes de programa/carrera.Tabla validada o documento.
Reporte operativoSeguimiento de procesos internos.Planilla o tablero simple.

Qué NO debe hacer Secretaría

  • Entregar reportes sin fecha de corte.
  • Mezclar fuentes sin explicitarlo.
  • Enviar bases con más información de la necesaria.
  • Presentar estimaciones como datos oficiales.
