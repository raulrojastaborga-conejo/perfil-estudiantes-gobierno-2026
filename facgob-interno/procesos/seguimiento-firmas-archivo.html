Seguimiento de firmas y archivo documental

Página interna para controlar documentos enviados a firma, estados pendientes, versiones finales y archivo de respaldo.

Qué cubre esta página

Incluye
  • Documentos enviados a firma.
  • Control de estados.
  • Versiones finales.
  • Archivo documental.
No incluye
  • Definir contenido académico del documento.
  • Emitir certificados.
  • Reemplazar el flujo propio de una resolución.
Cuidado

Un documento preparado no equivale a documento firmado ni a documento archivado.

Flujo base

Documento preparado→Enviar a firma→Registrar estado→Recibir firmado→Verificar versión→Enviar si procede→Archivar

Campos mínimos de seguimiento

CampoUsoCuidado
DocumentoIdentificar archivo o trámite.Usar nombre consistente.
FirmanteSaber dónde está pendiente.Confirmar cargo o rol.
Fecha de envíoSeguimiento de espera.No perder hilo de correo.
EstadoPendiente, firmado, observado, archivado.No cerrar sin versión final.
Ubicación finalCarpeta o repositorio.Evitar duplicados.

Qué NO debe hacer Secretaría

  • Usar borradores como documentos finales.
  • Enviar documentos sin revisar si están firmados.
  • Archivar múltiples versiones como definitivas.
  • Perder trazabilidad entre firma, correo y carpeta final.
