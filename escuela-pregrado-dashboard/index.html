Notas metodológicas

  • descripcion se usa solo como filtro global de matrícula; no se muestra como gráfico ni como eje principal.
  • La matrícula nueva se identifica con la columna TIPO, filtrando registros marcados como NUEVO/A.
  • La región de origen se toma desde REGION; si viene vacía o como 0, se usa REGION PSU como respaldo.
  • La hoja Titulados puede venir con una fila por profesor/rol de comisión; se deduplica por matrícula, RUT y fecha de resolución antes de agregar.
  • El procesamiento ocurre localmente en el navegador. El repo no publica datos personales.
